# 有效口径

优先级：用户本次要求 > 本文件对旧规格的明确补充 > cleaning-original.md。原样例只控制写作习惯，不覆盖当前源数据。

## 文件与日期
- 读单个非空XLSX数据页；固定18列，验证列标题与位置。数值缺失、非数字、非有限值按0，记录数量。格式错误不默默猜。
- 本skill当前展示币种为USD；多币种禁止直接加总，其他单币种需先明确改金额格式及绝对筛选值，不能隐式换汇。
- 以最大Day确定本期周一；最新日若非周日，比较上周相同星期区间并标部分周。任一比较区间缺日需核对，不能自动当0。
- 原文件多于两周时，主报告仍只比较最近两期；更多完整周仅用于核实连续趋势。
- 两周维度做并集，保留本期无花费但上期有花费的行。

## 表与公式
- 固定10张表及原主表列序不变；各页纵向放本期、上期、周度对比，右侧为分母底数和补充漏斗比值。表2的两期本身含环比区块，其他页下方显示对比。
- 主表ROAS、客单价、CTR、ATC Rate、转化率使用公式，聚合数值来自只读源文件；底数可查。导出数据是当次运行快照，不能声称修改源XLSX会自动刷新报告。
- 报告额外使用结账率=Checkout/ATC、支付率=Purch/Checkout。它们是聚合事件比值，不能保证同一用户漏斗；出现>100%时保留数据、标记异常，勿作流失诊断。
- 表9排序按本期产品花费汇总、产品key、同产品内购物次数降序；每个命名产品全额计入。没有多SPU时表9不一定大于全店，校验应检查实际乘数，不能强制大于。
- 国家为空/nan被排除时，国家表+剔除项才与总额一致。unknown字符串是原始Country值，保留。

## 来源与命名
- `ad_type`/`ad_source`来自AdName扫描类型段及下一段，用于表2和周报的VID/合创/UGC/IMG汇总。VID包含全部视频来源，UGC也可包含图片，彼此交叉。
- `id_source`从素材ID前缀提取，用于表6/7/9。例：h260212v02-mix可在广告命名中归ugc，而ID来源为合创。两者同时保留。
- ID key仅小写+压缩空格。连字符与下划线、空格的位置差异不自动合并，避免误归同一素材。达人单独去首尾分隔符后归一。
- 每期显示名取归一组内**各原始写法总花费**最高者，不取最高单条广告写法。零花费并列时按名称稳定排序。
- 产品原正则在真实数据中漏掉 S326TS265X、S326KS248Y；明确扩为 `[A-Za-z]{1,2}\d{2,3}[A-Za-z]{1,2}\d{3}[A-Za-z]?`，要求完整token边界；末尾X/Y属于产品编码，不丢弃、不解释业务含义。
- S325JS7864、S124TY87_BLACK、sg等不符合结构，不截取为看似正确产品；标Unknown并保留原字符串到validation.json。其他广告维度仍完整计入。
- 落地页移除连续的“ - 广告副本”后缀，而非只去掉一次；之后按清洗key汇总。
- 清洗原规格第6节提到“其他(无名)”，与表8最新规则冲突时，以表8明确的无名排除为准。
