# 周报写作与重点筛选

依据原周例会结构及用户修改后的《周报 (2).docx》两期复盘。每次必须同时读 [analysis-writing.md](analysis-writing.md)，这是用户最新确认的分析深度与建议边界，优先于本文件旧句式示例。只写数据支持的内容，可以提出有依据的建议；运营事项由用户自行补充，不追问。

## 固定结构
1. 标题 `YYYYMMDD-YYYYMMDD周例会`，一行本期/上期日期及USD。
2. 上周重点工作&Todo；本周重点事项、上周To-Do List保留空位。
3. 花费：一段全店总述；“从素材类型来看”依次视频、合创、IMG、UGC、Ecom、Camp、Catalog/Slide；“从受众结构来看”依次ASC、非ASC、LAL、INT。
4. 受众：下钻到值得关注的具体受众，避免重复上一节大类；样例此处主要是表图，新增文字遵守其段落习惯。
5. 落地页：先整体客单价与转化指标，再主要页面如shopall/bestseller/fall；页面名单根据当前数据选择。
6. 国家：主要市场优先，再写有体量的增长/下降市场；不机械罗列全部国家。
7. 素材：VID → 合创 → UGC → IMG。各段先汇总，再“具体素材”或“测新素材”；合创可按达人作小标题，给完整素材ID。图片模板分析并入IMG，不额外创造大章节。产品编码只作为素材关联产品注释，需要时用表9核对。
8. 本周计划、素材需求留空。不复制旧视频、截图、截图占位文字或无效链接。

## 段落习惯
- 用中文连贯短段落，主题名或素材ID加粗。避免把报告改成分析清单、复杂表格或管理层摘要。
- 一段围绕当周实际问题组织，选关键数字解释成本、客单价或转化环节，必要时提出具体建议。不机械套句，不统一收尾“继续观察”。
- 总述示例形状：本周花费环比下降X%，从$A降至$B；GMV从$C提升至$D，环比增长Y%；ROAS从E提升至F。然后说明花费规模与效率是否同向变化。
- 素材示例形状：**具体ID**本周改善明显，花费基本持平，ROAS从2.00升至4.00，GMV增加…，订单从…增加至…。在相近花费下产出增长，可继续观察稳定性。
- 下降例：**具体ID**花费增长，但GMV下降，ROAS从…降至…。若购物次数与客单价都降，可同时指出；不直接写“素材疲劳，暂停”。
- 金额两位小数、比率/ROAS两位小数、购物次数整数（源数据若出现非整数购物次数需检查，不能擅自取整改变事实）。环比使用未取整数值，不能用展示ROAS再算。
- 变化比较用“提升了X个百分点”时是两个百分比直接相减；“环比X%”是相对变化，不混用。
- `ROAS从2升到4`是环比增长100%，可以写“本周效率明显改善”。没有连续三期证据，不写“形成持续增长趋势”。

## 选择重点
先看当前与上期的规模、绝对增减额，随后看相对变化。
- 全店、核心素材类型、主要市场、主力落地页保持覆盖，但稳定方向简写，深度留给重要变化；无实质花费的分类不硬凑段落。
- 素材ID同时覆盖：主要出单素材、明显改善、明显下降、上期无花费本期有产出、有花费但未出单。不是只挑正面，也不是全量排行。
- 用 `signals` 作为候选名单，补查主要花费/GMV排行和绝对GMV变动榜。signal没有命中不意味着不值得写。
- 默认筛选线见analysis-config.json：ROAS变动30%，花费达到max(100美元,全店0.5%)，GMV绝对变动1000美元；任一期订单<5视作小样本。这只是初始编辑筛选线，不是业务阈值或统计显著性。
- 花费下降、ROAS上升、GMV下降应写“缩量后效率提升，产出仍下降”；不能笼统称“增长”。
- 花费上升、ROAS下降、GMV上升应写“产出增长，但花费增长更快，效率回落”；不称全面恶化。
- 上期1单、本期多单的高增长要写订单基数；两期都有足够订单时再强调变化更有参考价值。
- “测新”只能说明**所给数据范围内**上期无花费、本期开始产生花费；若更早完整周有该ID，写重新出现花费，不能把ID中的日期直接当投放首日。
- 国家/落地页等互斥维度可比较绝对GMV增量贡献；素材类型和来源交叉，不能把图片+UGC增量相加当作净贡献。

## 分组对齐
总览与素材汇总使用同一 `structure` 口径，不复刻旧周报各页不一致数字。对具体ID默认用表6全范围值；若相同ID横跨不同类型/来源，说明全范围口径，或用 `structure_material` 算板块内值并明确范围。
合创段里的达人全来源汇总须标注“达人全来源”，与合创分类总额区分。只在`qa.nonasc_budget_spend`确认全是cbo时写“CBO/非ASC”。

## 证据边界与检查
不得由花费减少推定已降预算/暂停；不能由ROAS下降确认素材疲劳、缺货、季节或支付故障。用户2.5门槛仅用于源表全周期累计花费≥1000美元的素材筛选，不是周度、全店、国家或受众的通用目标。
结账率与支付率按事件比值描述，>100%时不作漏斗解释。LPV等分母为0时文本说明没有有效基数，不声称真实零效率。
可以写有数据依据的投放建议，明确对象、事实与待验证指标；不补写已经执行的操作，不输出无依据的预算比例。
交稿前查：段落与数字同向、分母一致、范围一致、关键异常没有遗漏、零基数有说明、未混用历史样例事实。用户希望“跟以往一样写”，不表示要保留原稿中的错数或无证据因果。
