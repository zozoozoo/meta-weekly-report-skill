## 1. 广告命名 `^` 分隔结构（统一小写，缺省 `np`）

### Campaign（第N段，从1计）
第1段 创建日期 / **第2段 系列类型(cov/asc/daba…)** / **第3段 预算类型(cbo/abo/asc)** /
第4段 目录 / 第5段 用户属性 / 第6段 优化师 / 第7段 自定义。
> ASC 判定用第2段、第3段（见 §5 表2 与踩坑#1）。

### AdSet（第N段，从1计）
第1段 日期 / 第2段 国家 / 第3段 转化位置 / 第4段 转化目标 /
**第5段 受众类型(int-xx / lal-xx / RMT / np / daba…)** / 第6段 归因 / 第7段 年龄 / 第8段 性别 / 第9段 自定义。
> 表3 用第5段；表4 不用此段，改用原始 Country 列。

### AdName —— ⚠️ 实际结构比 V4 文档多一段「站点」
真实生产数据的 AdName 在 SPU 段之后、素材类型之前，多插了一段**站点/市场**（如 `sg` / `ca`）。
因此**不能按固定段序号取素材类型/来源/落地页**，否则整体错位一位。

实际结构：
第1段 创建日期 / **第2段 素材ID** / **第3段 SPU(+Color)** / **第4段 站点(sg/ca)** /
**第5段 素材类型** / **第6段 素材来源** / **第7段 落地页** / 第8段 自定义（可空）。

> 7 段的广告只是没有第8段自定义，结构一致；2 段的是 catalog 单层广告（走 §5 表5 兜底）。

**自适应定位规则（关键）**：不写死段序号，而是**扫描所有段，找出取值 ∈ 素材类型集合的那一段**作为素材类型段，
其后一段为素材来源、再后一段为落地页：

```
TYPE_SET = {img, vid, video, pic, slide, acimg, acvid}
ti = 第一个 段值.lower() ∈ TYPE_SET 的段索引
若找到 ti：素材类型=段[ti]；素材来源=段[ti+1]；落地页=段[ti+2]
否则若 素材ID(第2段) 含 'catalog'：落地页=素材ID（catalog 单层兜底）；素材类型/来源留空
```

## 2. SPU + Color 解析（表9 用，来源=AdName 第3段）

编码正则（兼容单/双字母前缀）：`[A-Za-z]{1,2}\d{2,3}[A-Za-z]{1,2}\d{3}`
（兼容 `S225BS737` 与 `SW26DS115`）。

规则：
1. 第3段为空或 `np` → 无 SPU，跳过（该广告不进表9）。
2. **多SPU**：第3段含 `+`（如 `S225BS737_KHAKI+S225BS718_WHITE`）→ 拆成多个 SPU，
   **每个 SPU 全额计入该广告的花费/GMV/各指标（不均分）**。
   ⇒ 表9 等产品级表花费合计会 > 全店总额，**仅用于单款横向比较，不可与全店加总**。
3. **颜色**：编码后 `_颜色`，统一大写。
4. **老款颜色混入款号**（带 `-`，如 `S124TY872-CREAM`）：真实 SPU 取 `-` 前（`S124TY872`），
   颜色取 `-` 后，归并为 `S124TY872_CREAM`，避免拆成两行/颜色重复。
5. **裸写 SPU 无颜色补默认色**：
   `S225BS737→KHAKI, S225BS718→WHITE, S225TS698→WHITE, S325JS786→CREME,
    S325JS804→BLACK, S124JS443→STONE, S124TY863→BLACK`；老款裸写取 `-` 后色。
6. **颜色别名统一到产品 SKU 拼写**：
   `ITALIAN STRAW→ITLN STRAW, PERIWINKLE BLUE→PERIWNKLBL, HALOGEN BLUE→HAL BLUE, LIGHT GRAY→LT GRAY`。
7. 键写法：`SPU_颜色`（无颜色则仅 `SPU`）。

## 3. 统一指标口径（所有表通用）

**所有比率必须先按分组对分子分母求和，再重算比率；禁止对原始行比率直接平均。**
先对分组求和：花费、GMV、购物次数、链接点击、展示、落地页浏览(LPV)、加购(ATC)。再：

| 指标 | 公式 |
|---|---|
| ROAS | GMV ÷ 花费 |
| 客单价 | GMV ÷ 购物次数 |
| 链接点击率 | 链接点击 ÷ 展示 |
| 加购率 | 加购(ATC) ÷ **落地页浏览(LPV)** |
| 转化率 | 购物次数 ÷ **落地页浏览(LPV)** |

> 分母为 0 → 结果取 0。加购率/转化率分母是 **LPV**，不是链接点击（修正后口径）。

表3/4/5/6/7/8 统一列：`维度名 | 花费 | GMV | 购物次数 | ROAS | 客单价 | 链接点击率 | 加购率 | 转化率`，按花费降序。

## 4. 时间粒度与环比（表2 用）

- 自适应粒度：数据覆盖 1 天→日；2 天→单日环比；≥3 天→周度。
- 周度切分：以数据最后一天所在**自然周（周一为起点）**为本期，前一自然周为上期。
- 环比 =（本期 − 上期）÷ 上期。
- 上期无基准 / 上期为 0 → 显示「新增/-」，**禁止输出 #DIV/0!**。
- 说明页与表2 标题注明数据维度与本期/上期日期范围。

## 5. 各表生成逻辑（固定 10 张，顺序固定）

**① 说明_口径**：数据维度、本期/上期日期、全店总花费/总GMV/ROAS、环比规则、
表2 复合分类与 SUM 的区别、统一指标公式、ASC 判定、多SPU 归因、命名站点段适配说明。

**② 表2_花费结构（复合堆叠表）**：各行可能重复计入，不要求加总=100%；**仅 SUM 行为真实全店汇总**。
列：`分类 | 花费 | 花费环比 | GMV | GMV环比 | ROAS | ROAS环比 | 花费占比 | GMV占比`。
固定行顺序与判定：

| 行 | 判定 |
|---|---|
| video-视频 | 素材类型 ∈ {vid, video, acvid} |
| 合创 | 素材来源 = 合创 |
| img-图片 | 素材类型 ∈ {img, pic, acimg} |
| ugc-红人素材 | 素材来源 = ugc |
| ecom-电商图 | 素材来源 = ecom |
| camp-广告图 | 素材来源 = camp |
| catalog-目录 | 落地页含 catalog |
| slide-幻灯片 | 素材类型 = slide |
| **SUM-全店汇总** | 全部广告（唯一真实总计） |
| RMT-再营销 | AdName 或 Campaign 含 `dpa` |
| 拉新受众 | 非 RMT |
| ASC-无受众 | Campaign 第2段 **或** 第3段 = asc |
| 非ASC | 非 ASC |
| lal-类似受众 | 受众(AdSet第5段) 以 lal 开头 |
| int-兴趣词 | 受众 以 int 开头 |
| ADP | 落地页 以 adp 开头 |
| PDP | 落地页 以 pdp 开头 |

- 花费占比 = 该行花费 ÷ SUM行花费；GMV占比同理。环比对每行花费/GMV/ROAS 分别算。
- pic 归 img 行、acvid 归 video 行、acimg 归 img 行。

**③ 表3a_受众大类 / ④ 表3b_受众明细**（来源 AdSet 第5段）：
先统一小写、合并多余空格。大类映射：int 开头→int；lal→lal；rmt→RMT；空或 np→np；daba→daba；其余→其他。
3a 按大类汇总；3b 按受众明细词汇总（空记 np）。

**⑤ 表4_国家**（来源原始 Country 列）：直接按 Country 分组；Country 为空/`nan` 不计入。

**⑥ 表5_落地页**（来源 AdName 落地页段，保留前缀）：
清洗——去 ` - 广告副本` 后缀；`adp+xxx`→`adp-xxx`；统一小写；空则剔除。
另加「形式」列：adp 开头→ADP；pdp→PDP；含 catalog→Catalog；其余→其他。
列：`落地页 | 形式 | …指标`。

**⑦ 表6_素材ID**（来源 AdName 第2段）：
先按**归一化 key**（小写 + 压缩多余空格）合并同一素材的大小写/空格变体
（如 `Jasmina-v25082801` 与 `jasmina-v25082801` 视为同一素材），**显示名取组内花费最高的原始写法**。
再对每行**拆分素材ID**为「达人名 / 类型 / 编号 / 后缀」四列，加「素材来源」「需复核」列。
列：`素材ID | 达人名 | 类型 | 编号 | 后缀 | 素材来源 | 需复核 | …指标`。**编号存为文本，保留前导零**（导出时单元格格式设为 `@`）。

> **素材来源解析（从素材ID）**：
> 前缀映射 `ip→IG热帖, h→合创, p→图片, v→视频, u→ugc`。
> - 规则1：匹配 `(开头或_或-)(ip|h|p|v|u)紧跟数字` → 对应来源（兼容 6 位老日期如 `Jasmina-h072401`）。
> - 规则2：无类型字母但形如「名字+数字」（如 `Jasmina-724`）→ **合创**。
> - 含 catalog / 等于 np / 都不匹配 → **其他**。

> **素材ID 拆分规范（达人名 | 类型 | 编号 | 后缀，表6/表8 共用）**：
> 以「编号」为锚点——**编号 = 从左到右第一处连续 ≥4 位的数字**（`\d{4,}`），以它分界：
> - 左侧 before → 达人名 + 类型：取 before 中**最后一个**分隔符（`_ - 空格`）位置 k；
>   有 k → 达人名=before[:k]（去首尾空白/分隔符）、类型=before[k+1:]；无 k → 达人名空、类型=before 全部。
> - 右侧 after → 后缀：去掉**一个**前导分隔符后剩余部分（去首尾空白）；后缀内部的 `_` 不再切分（`inspo_2`、`M8_dark` 整体保留）。
> - 编号**按文本存储、保留前导零**（`0823`/`081601` 不可转数字）；大小写原样保留（合并另靠归一 key）。
> - 无 `\d{4,}` → 四字段留空并标记「无数字编号」；其它保守边界（版本号 `v1`、超长后缀含SPU、类型偏长）打标「需复核」不猜测。
> - 逐字对拍样例：`alexearlsstyle_h26052201`→(alexearlsstyle,h,26052201,∅)；`p26051452-inspo_2`→(∅,p,26051452,inspo_2)；
>   `Jasmina-v081601-Augw3`→(Jasmina,v,081601,Augw3)；`atgreenwell-v0823`→(atgreenwell,v,0823,∅)；`h260205v1-mix`→(∅,h,260205,v1-mix)。

**⑧ 表7_图片模板**（仅 素材来源=图片）：按模板号汇总。
> ⚠️ **模板号提取（已修复 bug）**——旧逻辑 `inspo_\d+` 只认纯数字，漏掉 `inspo_ai6` 等带字母后缀。
> 正确顺序：
> 1. `inspo[_\-]?([A-Za-z0-9]+)` → `inspo_` + 捕获组（小写）。兼容 `inspo_2 / inspo_1 / inspo_ai / inspo_ai5..ai8`，
>    且遇到 `-` / `+` 等分隔符自动截断，不会把后面的 SPU 带进来（如 `p26061802-inspo_ai8-S126TS136_WHITE+…` → `inspo_ai8`）。
> 2. 否则 `(?<![A-Za-z])M(\d+)` → `m` + 数字（如 `M16`→`m16`）。
> 3. 否则含 `mix` → `mix`。
> 4. 都不匹配 → `(无模板号)`。

**⑨ 表8_红人**（**全来源**，不限合创）：凡素材ID能拆出「达人名」（见表6 拆分规范）的广告**全部计入**，
按达人名**大小写/空格归一**（小写）后汇总，**显示名取组内花费最高的原始写法**。
拆不出达人名的（纯编号如 `p26051452-ac`、`v26080501`）**不计入表8**（不再保留「其他(无名)」行）。
> ⚠️ 修正要点：旧版仅取「素材来源=合创」会漏掉 ugc/视频里带达人名的广告（如 `Jasmina_u26072404`、`atgreenwell-v0823`），
> 导致红人金额严重偏小。现改为全来源提取。

**⑩ 表9_产品x素材**（产品 × 素材ID 明细）：
每行 = SPU+Color × 素材ID × 素材来源。多SPU全额计入。
列：`SPU+Color | 素材ID | 素材来源 | 花费 | GMV | 出单数 | ROAS | 客单价 | 转化率`。
排序：先按各产品总花费降序（同产品行聚在一起），同产品内按出单数（购物次数）降序。

## 7. 历史踩坑清单（复现时必须规避）

| # | 问题 | 正确处理 |

| 1 | ASC 判断只看一段 | Campaign 第2段 **或** 第3段任一 = asc |

| 7 | 红人名+纯数字款识别失败 | 名字+数字型归合创 |
| 8 | 加购率/转化率分母用了链接点击 | 改为 **落地页浏览(LPV)** |
| 9 | 落地页脏数据 | 去 `- 广告副本`、`adp+`→`adp-`、catalog 单层兜底 |
| 10 | 受众大小写/空格重复 | 统一小写、合并空格 |
| 11 | 多SPU均分失真 | **全额计入**，产品级表标注不可全店加总 |
| 12 | 比率直接平均 | 先聚合求和再重算 |
| 13 | **命名多出「站点」段致错位** | **不写死段序号，按素材类型取值自动定位素材类型/来源/落地页段** |
| 14 | **表7 模板号漏识别** | **`inspo[_\-]?([A-Za-z0-9]+)` 捕获字母后缀（inspo_ai6 等），并在分隔符处截断** |
| 15 | **表6 同素材大小写/空格未合并** | **按归一 key（小写+压空格）合并，显示取花费最高原始写法** |
| 16 | **表8 仅取合创致红人金额严重偏小** | **改全来源：凡能拆出达人名即计入；排除无名；归一合并** |
| 17 | **编号前导零丢失** | **编号按文本存储，导出单元格格式设 `@`（`0823` 不转数字）** |
